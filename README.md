## 015 · 出门时间倒推器

**[打开出门时间倒推器 →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/leave-plan.html)**

填写约定到达日期、时刻、预计路程、想提前到达的分钟数，以及准备步骤，点击“倒推时间”。工具从终点向前排，显示何时开始准备、何时出门，并逐段列出时间表，支持完整复制。

```text
约定：2026-11-04 09:00（固定 UTC+08:00）
路程：35 分钟；想提前到达：10 分钟
准备步骤（每行名称 + 空格 + 分钟）：
洗漱 20
早餐 15
收包 10
→ 07:30 开始准备，08:15 出门，08:50 提前到达
```

- 提前到达时刻 = 约定时刻 − 提前量；出门时刻再减路程，开始准备时刻再减全部准备时长。步骤按输入顺序连续执行，不自动并行、排序或合并同名步骤。
- 路程为 0–1,440 分钟，提前量为 0–240 分钟，均须为整数。提前量安排在抵达后的机动时段；额外路况余量请计入路程。
- 准备步骤每行一个，以空格或 Tab 分隔名称和整数分钟。最多 8 个非空行，每步 1–240 分钟，名称最多 40 个 Unicode 码点，原始步骤输入最多 2,000 个 UTF-16 码元。名称可含空格；不解析“20分钟”“半小时”或小数。
- 跳过空行；准备步骤完全留空表示不需要准备。零路程或零提前量不生成额外时段。超限、部分填写或不支持的字符会报错，不截断输入。
- 所有时刻使用固定 UTC+08:00，精确到分钟，不做地区时区或夏令时转换。输入日期及倒推结果均限于 1900-01-01 至 2100-12-31；跨午夜、跨月、跨年和公历闰日会正确标明完整日期。
- 初始和重置日期为设备时钟换算的 UTC+08:00 明天。示例固定使用上述合成安排。修改参数后清除旧结果，支持 ⌘ / Ctrl + Enter；无法自动复制时选中完整时间表供手动复制。
- 耗时由用户估计，不读取定位、交通或实时路况，不保证实际到达。所有计算在本地完成，不上传、不保存历史，页面可下载后离线使用，无需安装依赖。

## 014 · Wi-Fi 共享二维码

**[打开 Wi-Fi 共享二维码 →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/wifi-qr.html)**

填写网络名称、网络类型和密码，点击“生成二维码”，确认网络名称后下载 PNG。让获准连接的访客使用支持 Wi-Fi 二维码的相机或应用扫描，省去手抄长密码。工具不会连接网络或验证密码是否正确。

- 支持常见 WPA/WPA2 个人密码网络、无密码网络和隐藏网络选项；不处理企业账号、证书、网页认证、WEP 或 WPA3 专用配置。手机、扫码应用和路由器决定实际连接兼容性。
- 网络名称为 1–32 个 UTF-8 字节；密码为 8–63 个 UTF-8 字节，或 64 位十六进制原始密钥。中文和 emoji 通常占多个字节。名称和密码区分大小写，保留首尾空格，不做 Unicode 归一化。控制字符和无效 Unicode 会报错，不截断输入。
- 使用 [ZXing 记录的 Wi-Fi 内容格式](https://github.com/zxing/zxing/wiki/Barcode-Contents#wi-fi-network-config-android-ios-11)，转义反斜杠、分号、逗号、冒号和双引号。纯十六进制外观的文本加引号，64 位原始密钥保持未加引号；无密码模式不编码密码，并清空、禁用密码框。
- 二维码使用 UTF-8 ECI、M 纠错级别、四格白边；PNG 每格 8 像素，黑白无透明底。请保留白边，不裁剪、不加图案，避免严重压缩。
- 修改网络信息或隐藏选项后清除旧二维码，导出期间修改输入也不会下载过期图片。显示密码仅改变可见性。支持 ⌘ / Ctrl + Enter；清空或刷新丢弃输入和当前结果。
- “试试示例”使用虚构网络 `Example-Guest` 和示例密码 `ExampleOnly123`，不连接真实网络。
- 二维码和导出的 PNG 包含网络凭据，请只分享给获准连接的人；清空页面不会删除已经保存或分享的图片。
- 无需注册，不上传、不保存历史、不加载外部资源，内容安全策略禁用连接请求。编码器已内嵌，下载本页后可离线生成，无需安装依赖。

二维码编码器内嵌 **Project Nayuki QR Code generator v1.8.0（ES6）**，保留完整 MIT 版权和授权说明。来源为[官方发布文件](https://github.com/nayuki/QR-Code-generator/releases/download/v1.8.0/qrcodegen-v1.8.0-es6.js)，内嵌源文件 SHA-256 为 `6a1116192ed1dd67fa1bf31e77f5817103d71c23bbac24c382e698b7668bdd01`。项目说明见 [Project Nayuki](https://www.nayuki.io/page/qr-code-generator-library)。

## 013 · 日历事件生成器

**[打开日历事件生成器 →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/calendar-event.html)**

把活动名称、起止时间、地点和备注填一次，点击“生成并预览”，确认后下载 `.ics` 文件，在支持该格式的手机或电脑日历中打开或导入。工具只生成文件，不直接写入日历、不发送邀请。

```text
小组讨论，2026-11-02 14:30–15:30（输入按 UTC+08:00）
地点：社区活动室
→ 文件写入 UTC 06:30–07:30，日历按自己的显示时区换算

全天活动，2026-11-01 至 2026-11-03（含结束日）
→ 覆盖三天，文件内部的结束日期为 2026-11-04
```

- 定时活动固定按 UTC+08:00 解释，不查询地区时区或夏令时规则。开始、结束精确到分钟，结束须晚于开始；跨午夜须选次日为结束日期。导入后请核对日历显示时区。
- 全天活动不使用时钟或时区，起止日期均计入，文件内按 iCalendar 的不含结束日规则写入下一天。日期输入范围为 1900-01-01 至 2100-12-31，自动处理跨月、跨年和公历闰日。
- 名称必填，最多 80 个 Unicode 码点；地点可留空，最多 120 个；多行备注最多 2,000 个。去掉首尾空白，拒绝无效 Unicode 和不支持的控制字符；单行字段不允许换行。超限报错，不截断。
- 使用 UTF-8、CRLF 行尾，转义文本中的反斜杠、逗号、分号和换行；长行按最多 75 字节折行，不拆开 Unicode 字符。格式依据 [RFC 5545](https://www.rfc-editor.org/rfc/rfc5545.html)；事件含独立随机 UID、生成时间和起止日期。
- 只生成一件事，不设置重复规则、提醒或邀请；重复导入可能产生重复事件，请在日历应用中确认。导入入口因应用不同，必要时使用其网页版或电脑客户端。
- 可复制活动信息、查看原始文件内容。修改输入或切换全天模式后清除旧结果，支持 ⌘ / Ctrl + Enter；无法自动下载或复制时显示内容供手动保存或复制。
- “试试示例”使用上面的合成讨论活动，不访问外部服务。日期初始值和清空后的默认日期按设备时钟换算到 UTC+08:00 的今天。
- 无需注册、本地生成、不上传、不保存历史，刷新或关闭会丢弃输入。可下载页面离线使用；事件标识需要浏览器支持 `crypto.randomUUID`，不可用时会明确提示。

## 012 · 文件校验器

**[打开文件校验器 →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/file-checksum.html)**

下载或备份后，选择文件，粘贴可信来源提供的 SHA-256，点击“计算并核对”。页面会显示计算出的文件摘要，以及与预期值一致或不一致的结果。预期值也可留空，此时只计算摘要，不声称已核对。

```text
内容恰为 abc、没有换行的文本文件（3 字节）：
SHA-256 = ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```

- 支持任意文件类型及空文件，一次一个，最大 64 MiB（67,108,864 字节）。超限拒绝读取；文件读取失败、字节数不符或加密能力不可用时明确报错。
- 预期 SHA-256 须为 64 位十六进制字符，忽略首尾空白和大小写。不解析文件名、SHA256: 前缀、命令或行内空格，不截断多余字符。
- 使用浏览器内置 Web Crypto 对原始文件字节计算 SHA-256。摘要不包含文件名、路径、修改时间或文件类型；相同内容改名不改变结果。换行、编码或其他字节变化会影响摘要。
- 需要将文件读入内存；大文件请使用本机工具。修改文件选择或预期值、清空后会立即清除旧结果，先前的异步计算不会覆盖新的输入或结果。
- 可复制单独的 SHA-256 或带文件名、精确字节数、预期值和判定的完整报告；自动复制不可用时显示并选中内容供手动复制。支持 ⌘ / Ctrl + Enter。
- “试试示例”只在本地生成上述 abc 文件并填入对应校验值，不访问网络、不修改你的文件。
- 校验值相同不能单独证明文件来源可信或没有恶意内容。请从可信来源获取预期值。
- 无需注册，不上传文件、不保存历史。刷新或关闭后丢弃当前选择。页面可下载后离线使用；需要支持 Web Crypto 的浏览器和 HTTPS 或本机可信环境，不支持时提示原因。

## 011 · 清单核对器

**[打开清单核对器 →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/list-compare.html)**

采购、打包或交接资料时，把“应该有”的基准清单和“实际有”的清单各粘贴一份，每行一项，点击“核对清单”。结果按缺少、多出和共有项目分别列出，可复制完整报告。

```text
应该有：牙刷、牙膏、充电器、水杯、USB 线（实际输入时每行一项）
实际有：牙刷、充电器、usb 线、纸巾、牙刷
→ 缺少：牙膏、水杯；多出：纸巾；共有：牙刷、充电器、USB 线
→ 实际清单有 1 个重复行，已按项目合并
```

- 默认忽略英文字母 A–Z 大小写，也可取消。自动跳过空行、去掉每行首尾空白，保留行内空格；支持 Windows、Unix、旧 Mac 换行。
- 两侧各最多 1,000 个非空行、100,000 个 UTF-16 码元；每项最多 200 个 Unicode 码点。超限明确报错，不截断内容。允许一侧为空，两侧均无项目时报错。
- 以整行名称核对项目是否出现，重复项目只算一项并提示重复行数；不核对数量。同名的人或物品请加编号。“牛奶 ×2”与“牛奶”属于不同项目。
- 不解析编号、勾选框、逗号或近似拼写，不自动合并全角半角、简繁体或不同 Unicode 编码。请先统一写法。
- 缺少项和共有项按基准首次出现顺序显示，共有项采用基准文字；多出项按实际清单首次出现顺序显示。结果列表可滚动，完整复制不受列表可视高度限制。
- 可交换两份清单来调整核对方向。修改、交换、清空或改变大小写规则后清除旧结果；支持 ⌘ / Ctrl + Enter，自动复制不可用时显示并选中完整报告供手动复制。
- 无需注册、本地处理、不上传、不保存历史。刷新或关闭会丢弃输入；页面可下载后离线使用。

## 010 · 文件传输时间估算器

**[打开文件传输时间估算器 →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/transfer-time.html)**

下载资料或上传视频之前，先估算要等多久。输入文件大小、传输速度和各自单位，点击“估算时间”。速度比例默认 100%；也可自行设定较低比例比较情景，“试试示例”会演示 80% 的情况。

```text
10 GB，以 100 Mbps 的 100% 恒定传输 → 约 13 分钟 20 秒
10 GB，以 100 Mbps 的 80% 恒定传输  → 约 16 分钟 40 秒
100 Mbps = 12.5 MB/s
```

- 容量支持 MB / GB / TB 和 MiB / GiB / TiB；前者按 1,000 进位，后者按 1,024 进位。
- 速度支持 Mbps / Gbps / MB/s / MiB/s / KB/s / KiB/s。1 字节为 8 比特；KB/s、KiB/s 分别按 1,000 和 1,024 字节/秒。
- 容量和速度均须大于 0、不超过 1,000,000，最多 3 位小数；速度比例为 1–100 的整数。参数错误会明确报错。
- 以整数分数运算估算耗时，向上取整到整秒。极小传输显示为约 1 秒，大数值也不依赖浮点整数精度。有效速度折合 MB/s 约值最多显示 3 位小数，极小速度标为 `<0.001`。
- 假设所选有效速度恒定，仅估算传输数据的时间，不含连接准备、排队或暂停。实际速度受网络、服务器、磁盘和协议开销等影响；比例由用户设定，不是测速结果或耗时保证。
- 可复制包含输入、有效速度、100% 理论耗时和条件说明的结果。修改参数会清除旧结果，支持 ⌘ / Ctrl + Enter；无法自动复制时选中结果供手动复制。
- 本地计算，无注册、不上传、不保存输入；页面可下载后离线使用。

## 009 · 时间段合计器

**[打开时间段合计器 →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/time-total.html)**

一天学了几段、休息了几次，一共用了多久？每行输入一个起止时间，点击“合计时长”，查看精确到分钟的总时长、首末跨度和期间间隔，并复制完整结果。

```text
09:00-11:30
13:00-14:15
15:00-16:00
→ 合计 4 小时 45 分钟，十进制 4.75 小时
→ 首末跨度 7 小时，期间间隔 2 小时 15 分钟
```

- 最多 100 段，输入上限 10,000 个 UTF-16 码元；超限报错，不截断输入。空行跳过，结果按开始时间排序。
- 支持 `9:00` 或 `09:00`；连接符可用 `-`、`–`、`—`、`~`、`～` 或“至”。不解析标签、备注、秒数或一行中的多个时段。
- 结束必须晚于开始。`24:00` 只能用作结束时间；所有时段须属于同一天。跨午夜请按日期拆开分别合计，例如前一天 `23:00-24:00`、后一天 `00:00-01:00`。
- 首尾相接的时段可正常合计。重复、部分重叠和包含关系都会报错并指出原始行号，不自动合并或重复计时。
- 期间间隔只统计最早开始至最晚结束之间未填的时间；总时长 + 期间间隔 = 首末跨度。小时分钟结果精确到分，十进制小时约值四舍五入到 2 位小数。
- 修改输入后清除旧结果。支持 ⌘ / Ctrl + Enter 合计；复制不可用时显示并选中结果供手动复制。
- 本地计算，不上传、不保存历史。清空或刷新丢弃输入，可下载页面离线使用。

## 008 · 随机分组器

**[打开随机分组器 →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/random-groups.html)**

学习讨论或活动需要临时组队？每行粘贴一位成员，填写组数，点击“随机分组”。完整名单会随机打乱再分组，每人只出现一次，各组人数相差最多一人。8 人分 3 组时，人数为 3、3、2。

- 支持 2–200 人、2–50 组，组数不超过人数；每个名字最多 40 个 Unicode 码点，原始输入最多 20,000 个 UTF-16 码元。
- 跳过空行、去掉名字首尾空白。英文名字不区分大小写查重；重复名字会报错，同名者请加编号。不会自动合并不同 Unicode 写法，不会悄悄删除成员。
- 使用浏览器 `crypto.getRandomValues` 随机源，通过拒绝采样生成索引，再进行 Fisher–Yates 打乱。随机源不可用时明确报错，不生成伪装成功的结果。
- 仅均衡人数，不按特长或其他条件分组；人数除不尽时前面的组多一人。再次点击可重新分组，结果有可能与上次相同。
- 可复制完整分组与每组人数。修改名单或组数后立即清除旧结果；支持 ⌘ / Ctrl + Enter。无法自动复制时显示并选中结果供手动复制。
- 名单与结果只在当前页面处理，不上传、不保存历史。清空或刷新后丢弃输入；页面可下载后离线使用。

## 007 · 日期推算器

**[打开日期推算器 →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/date-offset.html)**

2026-10-26（星期一）之后 10 个周一至周五 → 2026-11-09（星期一）

- 不计起始日，从下一天或前一天开始数；0 天返回原日期，即使原日期是周末也不改变。

- 天数为 0–36,500 的整数。起始日和结果均限于 1900-01-01 至 2100-12-31；越界会报错，不截断或偷偷改日期。
- 使用完整日历日期，正确处理跨月、跨年和公历闰年；计算不依赖本地时区的 24 小时时长，不受夏令时切换影响。无具体时刻或时区换算。
- “使用今天”采用设备的本地日期。“试试示例”使用上方第二个例子，演示周末处理。
- 修改日期、天数、方向或计数方式后清除旧结果。支持 ⌘ / Ctrl + Enter；无法自动复制时显示并选中结果供手动复制。
- 无需注册、本地计算、不上传、不保存历史。页面可下载后离线使用。

## 001 · 链接净化器

粘贴一个或多个完整链接，点击“净化链接”，复制结果即可。每行一个，最多 200 行。

```text
https://example.com/article?id=42&utm_source=newsletter&utm_medium=email#read
↓
https://example.com/article?id=42#read
```

- 移除常见追踪参数：`utm_*`、`fbclid`、`gclid`、`dclid`、`gbraid`、`wbraid`、`msclkid`、`twclid`、`ttclid`、`igshid`、`mc_cid`、`mc_eid`、`li_fat_id`、`vero_id`、`_hsenc`、`_hsmi`。
- 保留其他参数、重复参数、原编码与顺序、`#fragment`。不会泛删 `ref`、`source` 等可能有功能作用的字段。
- 检测到常见签名、令牌、认证或有效期字段时，整条链接原样保留。此检测是启发式规则，不能覆盖所有网站。
- 不支持的协议、无效行、含用户名密码的链接会标明原因，并原样保留，避免静默丢失输入。
- 不展开短链，不访问链接目标，不会上传输入。页面没有分析脚本、广告、外部字体或第三方依赖。
- 修改输入后会立即清除旧结果，避免误复制过期结果。复制权限不可用时会选中结果，支持手动复制。

移除追踪参数可能影响少数网站的自定义功能；工具不能移除路径、片段或未知参数里的所有追踪信息，也不负责判断链接是否安全。请核对重要链接。
