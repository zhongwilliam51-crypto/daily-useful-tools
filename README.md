## 025 · 多人垫付结算器

**[打开多人垫付结算器 →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/group-settle.html)**

旅行或聚会中多人分别付过住宿、餐饮等费用时，每行填一个人的称呼、空格和垫付总额。列出所有参与者，未付过的人填 0，同一人的多笔支出先加总。点击“计算结算”后核对各人承担额及最后的转账清单，支持复制和 Ctrl / ⌘ + Enter。

- 只计算全员均摊的共同费用，全部金额须为同一币种。个人消费、不同分摊比例和已经还过的钱须先另行处理。本页不会发起转账。
- 示例：小林付 360、小周付 180、小陈付 0，总额 540，每人承担 180；小陈最后转给小林 180，小周无需再转。
- 全程用整数分计算。总额除不尽时，按名单顺序给前几人各多分 0.01；各人承担最多相差 0.01，承担总额与支出一致。
- 按名单顺序抵消应付与应收，不必逐笔互还原垫付款。转账最多人数减一笔，不保证笔数最少；总额为零或各人已付等于承担时无需转账。
- 支持 2–30 人，空行忽略，每项垫付 0–1,000,000，最多两位小数。使用点，不接受货币符号、千位分隔符、负数和科学计数法。称呼可含空格，最多 40 个 Unicode 码点，不支持控制字符；经首尾去空白和 NFC 规范化后须唯一，区分大小写。
- 原始输入最多 10,000 个 UTF-16 码元。修改输入会清除旧清单，复制时先选中完整结果，自动复制不可用时可手动复制。计算在浏览器本地完成，不上传、不保存，下载页面后可离线使用。

## 024 · 打印页码整理器

**[打开打印页码整理器 →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/print-pages.html)**

填入文件总页数和要打印的单页或完整范围，点击“整理页码”。结果按页序从小到大排列，合并连续页、移除重复页，并显示最终页数。核对后复制到打印窗口的自定义页码栏。常见的逗号与短横线范围用法见 [Adobe 打印设置说明](https://helpx.adobe.com/hk_en/acrobat/desktop/print-documents/set-up-and-print-pdfs/print-settings.html)。

- 示例输入为 `1, 3-5, 4, 8, 10-12`，文件共 12 页。结果为 `1,3-5,8,10-12`，共 8 页，合并一个重复页。
- 支持英文或中文逗号、顿号及换行分隔，忽略空片段。范围两端都计入，可使用短横线、长横线、波浪号或“至”。范围须从小到大填写。
- 总页数为 1–10,000。每次最多 200 个单页或范围，原始输入最多 10,000 个 UTF-16 码元。超出总页数、倒置范围或不完整表达式会指出出错项。
- 奇偶筛选按原文件页序号作用于已选页码。没有符合条件的页时，结果为空并禁用复制。重复数在奇偶筛选前统计。
- 这里使用文件中的页序号，从 1 开始。文档的印刷页码、封面编号和打印软件的逻辑标签可能与它不同，打印前须核对预览。
- 本地整理，无需上传文件，下载页面后可离线使用。点击复制先选中完整结果，再尝试自动复制，便于手动复制。

## 023 · 满减凑单计算器

**[打开满减凑单计算器 →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/cart-threshold.html)**

填写当前参与活动的商品金额、满减门槛、优惠金额和计划加购金额，点击“对照实付”。四项金额按同一币种填写，均以优惠前的合资格商品金额为准。

- 使用单次“满 X 减 Y”规则。原订单和加购后订单分别检查是否达到同一门槛，再各减一次优惠。结果显示两笔实付、差额及距离门槛的金额。
- 示例为当前 270、满 300 减 40、加购 30。原订单实付 270，加购后实付 260，少付 10。加购 55 时则实付 285，比原订单多付 15。
- 原金额已达到门槛时，原订单实付也包含该优惠。金额差额反映支付金额的变化，加购物品也会随订单增加。
- 每项金额接受 0–1,000,000，最多两位小数，使用点作为小数符号。门槛须大于零，优惠金额不得超过门槛。内部按整数分计算。
- 适用于参加同一优惠的商品。优惠叠加、运费和商品资格以结算页为准。工具在浏览器本地计算，下载页面后可离线使用。

## 022 · 香港时间换算器

**[打开香港时间换算器 →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/hong-kong-time.html)**

选好香港日期和时刻，点击“换算时刻”。工具显示伦敦、纽约、洛杉矶、悉尼、东京和 UTC 的同一时刻，可复制完整对照表。

- 输入使用固定 UTC+08:00，日期范围为 2000–2099 年，精确到分钟。输入框显示格式由设备设置决定，结果采用 24 小时制。初始值及“填入当前时间”采用设备时钟换成香港时间。
- 每张卡片含当地完整日期、星期、时间和 UTC 偏移。“前一天、同日、后一天”均相对输入的香港日期。
- 使用浏览器内置时区数据，通过 Intl.DateTimeFormat 按所选日期换算。冬夏偏移会随日期变化，夏令时结束时相同的当地钟面时间可通过 UTC 偏移区分。时区数据背景见 [IANA 时区数据库](https://www.iana.org/time-zones)。
- 日程较远时，临近日期请核对当地时间规则及浏览器数据是否更新。复制后保留日期和偏移，方便双方确认同一个时刻。
- 修改输入会清除旧结果，剪贴板不可用时会选中完整对照表供手动复制。页面在本地计算，下载后可离线使用。

## 021 · 电器用电估算器

**[打开电器用电估算器 →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/appliance-energy.html)**

输入一台电器使用时的平均功率、每天使用的小时和分钟，以及使用天数。点击“估算用电”查看每日和整段期间的耗电量。填入每度电的单价，还可估算期间电费，金额沿用单价的币种。

- 一度电等于 1 kWh。每天用电量是功率（W）乘以每日使用小时数，再除以 1,000。期间用电量等于每天用电量乘以天数。用电量换算可参考 [美国能源部用电说明](https://www1.eere.energy.gov/education/pdfs/lesson301.pdf)。
- 功率为 0–10,000 W，最多一位小数。时长使用整小时和整分钟，分钟为 0–59，每天合计不超过 24 小时。天数为 1–366 的整数。每度单价选填 0–100，最多四位小数。小数可用点或逗号。
- 示例为 120 W、每天 2 小时 30 分钟、使用 30 天。每天约 0.3 度，期间约 9 度。按示例每度 1.20 计算，期间电费约 10.80。
- 电器功率随运行状态变化时，尽量使用该时段的实测平均功率。铭牌功率可作粗估。单价按固定值计算，实际费用以账单的阶梯、分时和固定费用为准。
- 不足 0.01 度的非零用电量以 Wh 显示。电费以未舍入的用电量计算。工具在浏览器内运行，下载页面后可离线使用。

## 020 · 共同空档查找器

**[打开共同空档查找器 →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/shared-free-time.html)**

把两个人同一天、同一时区的空闲时间分别填入两栏。每行写一段，如 `09:00-11:30`。填好需要的最短分钟数，点击“找共同空档”。符合条件的时段按开始时间列出，结果可复制。

- 每人至少一段，最多 100 段和 10,000 个 UTF-16 码元。支持 H:MM 或 HH:MM，连接符可以是短横线、长横线、波浪号或“至”。空行跳过。
- 同一人的重复、重叠和首尾相接的时段先合并。两人时段只有端点相接时，没有可用的共同空档。
- 最短时长为 1–1440 的整数分钟，恰好等于最短时长也符合条件。没有够长的空档时，若两人有重叠，页面会显示最长的一段有多长。
- 24:00 只可作为当天的结束时间。跨午夜的时段请按日期拆开，分别计算。时区需要在输入前统一。
- 修改输入会清除旧结果。工具在浏览器本地计算，下载页面后可离线使用。剪贴板不可用时会选中结果供手动复制。

## 019 · 表格转 Markdown

**[打开表格转 Markdown →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/table-markdown.html)**

在表格中选中一个包含表头的矩形区域并复制。在工具中粘贴，点击“转换”，核对预览后复制源码。在 GitHub README 或 Issue 中把源码放在单独一段。也可按 Ctrl / ⌘ + Enter 转换。表格语法见 [GitHub Flavored Markdown 规范](https://github.github.com/gfm/#tables-extension-)。

- 输入为 Tab 分列、换行分行的纯文本，第一行为表头。支持 CRLF、LF 和 CR。至少一个表头非空，各行须有相同列数，末尾的空单元格也保留。末尾一个换行只结束当前行。
- 以双引号包住含换行或 Tab 的单元格。包裹中的双引号用两个连续引号表示。单元格内的 Tab 转为空格，去除每格开头和末尾的空格。行内换行导出为 `<br>`。
- 竖线、反斜杠、HTML 标签字符和常见 Markdown 格式符号会转义。预览展示转换前后的文字结构，实际排版由目标网站决定。
- 最多 200 行（含表头）、20 列和 50,000 个 UTF-16 码元。列数不一致或引号错误会指出对应行。仅转换粘贴的文字，适用于没有合并单元格的区域。
- 转换在浏览器内完成。无需注册、上传或安装依赖，下载页面后可离线使用。剪贴板不可用时会选中源码供手动复制。

## 018 · 打印缩放计算器

**[打开打印缩放计算器 →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/print-scale.html)**

以毫米输入原稿宽高、目标纸张宽高和每边留白，点击“计算缩放”。示例把 297 × 210 毫米原稿放在 148 × 210 毫米纸上，每边留 5 毫米，原方向可缩至 46.4%，旋转后可缩至 65.7%。

- 从纸张宽高各扣除两边留白，再取可用宽、高与原稿对应边的两个比例中的较小值。百分比向下取到一位小数。若打印界面仅接受整数，使用页面给出的向下取整值。
- 勾选方向比较后，另算交换原稿宽高的情况，选择可用比例较大的方向。显示比例相同时保留原方向。比例允许超过 100%。
- 原稿和纸张的每边可填 1–2,000 毫米，每边留白可填 0–500 毫米。最多一位小数，可用点或逗号作为小数符号。可用区域耗尽或建议比例低于 0.1% 时提示调整。
- 原稿尺寸包含文件自身留白。预留空间须包含打印机无法印到的边缘，四边要求不同时填最大值。示意图按居中绘制。
- 在原文件中按结果调整原稿方向，选目标纸张，再用打印软件的自定义缩放。打印前核对预览，确认软件与驱动支持该比例。操作入口可参考 [Adobe Acrobat 打印页面大小说明](https://helpx.adobe.com/acrobat/desktop/print-documents/set-up-and-print-pdfs/page-size.html)。
- 只计算尺寸和比例。无需选择或上传文件，下载页面后可离线使用。

## 017 · 文本限额裁剪器

**[打开文本限额裁剪器 →](https://zhongwilliam51-crypto.github.io/daily-useful-tools/text-limit.html)**

粘贴简介、标题或表单内容，选择目标网站采用的计数方式，填入上限并点击“检查并裁剪”。工具同时显示原文和结果的字符、UTF-8 字节与 UTF-16 码元数。核对后复制结果，也可用 Ctrl / ⌘ + Enter 重新计算。

- 字符以浏览器的 [Intl.Segmenter](https://tc39.es/ecma402/#segmenter-objects) 字素簇为准，组合 emoji 和带重音的字母可作为一个字符。UTF-8 字节通过 [TextEncoder](https://encoding.spec.whatwg.org/#interface-textencoder) 计算，UTF-16 码元是 JavaScript 字符串的长度。各网站可能采用不同规则。
- 任何计数模式下都保留符合上限的最长原文前缀。若下一个完整字符放不下，停止裁剪，不跳过它去补后面的短字符。比如示例“周末见！👩🏽‍💻”在 20 字节预算下只保留前 12 字节的“周末见！”。
- 保留空格和换行，不添加省略号。网页输入框统一使用 LF 换行。上限接受 0–100,000 的整数，原文最多 20,000 个 UTF-16 码元。
- 需要支持 Intl.Segmenter 的浏览器。无需注册或上传，可下载页面离线使用。剪贴板不可用时会选中结果供手动复制。

## 016 · 联系人名片生成器
