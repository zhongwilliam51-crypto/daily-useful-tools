表格转 Markdown

从表格复制一块单元格，粘贴后就能生成 GitHub README 或 Issue 可用的表格。

01 / 粘贴单元格

列之间用 Tab 分隔，第一行为表头。最多 200 行、20 列和 50,000 个 UTF-16 码元。

粘贴后点击转换，或按 Ctrl / ⌘ + Enter。

02 / 复制 Markdown

表格预览

支持双引号包住的多行单元格。各行须有相同列数，空单元格保留。工具只转换粘贴的文字，样式、合并单元格和公式本身不随文本复制。

内容在当前浏览器处理。无需注册或上传，下载本页后可离线使用。
