小工具，解决一个真问题。

对照两份清单，
哪里漏了，一眼看见。

采购、打包或交接资料，把“应该有”和“实际有”各贴一份。找出缺少的、多出来的，以及两边都有的项目，省去逐行来回核对。

01 / 应该有

例如打包计划或交接要求；可留空。

02 / 实际有

例如已装进包里的物品；可留空。

每行一项，至少在一侧填入内容后核对。

03 / 核对结果

缺少 = 应该有但实际没有；多出 = 实际有但基准没有。

    没有缺少项目。

      没有多出项目。

        没有共有项目。

        两侧各最多 1,000 个非空行、100,000 个 UTF-16 码元；每项最多 200 个 Unicode 码点。超限会报错，不截断内容。支持 Windows、Unix 和旧 Mac 换行。

        自动跳过空行、去掉每行首尾空白，保留行内空格。按整行项目名称核对，不解析编号、勾选框、逗号或数量；“牛奶 ×2”与“牛奶”会视为不同项目。

        重复项目只算一项，并提示重复行数；本工具核对项目是否出现，不核对件数。同名的人或物品请加编号。按各自首次出现的顺序显示，共有项采用基准清单的文字。

        大小写选项只折叠 A–Z。不自动合并全角半角、简繁体、组合字符或近似拼写；请先统一写法。修改、交换或清空清单后会清除旧结果，支持 ⌘ / Ctrl + Enter 核对。
