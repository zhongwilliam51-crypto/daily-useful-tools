文件下好了，
内容真的一致吗？

下载或备份之后，用 SHA-256 核对文件内容。选择一个文件，粘贴来源提供的校验值；没有校验值，也可以先计算一份，留作以后比对。

01 / 选择文件与核对值

文件只在当前浏览器读取，不会上传。支持空文件和任意文件类型。

只粘贴校验值，不含文件名、SHA256: 前缀或命令；忽略首尾空白和英文字母大小写。

选择文件后开始；⌘ / Ctrl + Enter 也可计算。

02 / 文件指纹与核对结果

计算结果会显示在这里。

SHA-256 · 64 位十六进制

使用浏览器内置 Web Crypto 计算 SHA-256，只读取文件内容，不把文件名、修改时间或路径加入摘要。同一份内容改名后，校验值仍相同；换行或任何字节不同都会影响结果。

最多 64 MiB（67,108,864 字节），一次一个文件。计算时需要将文件读入内存；大文件请用设备自带的命令行工具。修改文件选择、预期值或清空后会清除旧结果；较早的计算不会覆盖新选择。

“一致”表示所算 SHA-256 与输入值相同，并不能单独证明文件来源可信或没有恶意内容。请从可信来源获取预期校验值。

“试试示例”在本地生成一个内容恰为 abc、没有换行的 3 字节文本文件，并填入对应校验值；不会下载示例或修改你的文件。

无需注册、不上传、不保存历史。刷新或关闭会丢弃当前结果。可下载页面离线使用；需要浏览器支持 Web Crypto，HTTPS 或本机可信环境下可用，不支持时会明确提示。
